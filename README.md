# Source Sight

Source Sight is a Chrome Manifest V3 extension that estimates whether images on a webpage were generated by AI. Image bytes are fetched, decoded, and analyzed locally in the extension. No image data is sent to a detection service.

This project is a submission for the [Poidh local AI image detector bounty](https://poidh.xyz/arbitrum/bounty/323). The linked bounty page is the source of truth for evaluation.

## What it does

- Scans ordinary webpage images automatically.
- Runs an ONNX image classifier with WebGPU and falls back to WebAssembly.
- Shows `AI`, `Real`, or `Uncertain` with a confidence percentage.
- Stores the verified model in IndexedDB for later offline inference.
- Uses metadata markers only as a small local signal; they are not required for detection.

## Model and data flow

The bundled model is the int8 ONNX export of CapCheck's CIFAKE-trained ViT classifier. It emits two logits, converted with softmax to an AI-generated probability. Source Sight uses a fixed AI threshold of `0.65`.

The exact model URL, revision, SHA-256 digest, input shape, normalization, and threshold are recorded in [public/model-manifest.json](public/model-manifest.json). The model is downloaded and verified during build setup, then bundled into the extension. Runtime inference only loads the bundled or locally cached bytes and has no model-download fallback.

The model repository is Apache-2.0 licensed. That third-party license applies to the weights; the Source Sight extension code is MIT licensed.

## Requirements

- Node.js 20 or newer
- Google Chrome 121 or newer

## Install and build

```sh
npm install
npm run download:model
npm run verify:model
npm run build
```

The model file is intentionally ignored by Git. This keeps the repository manageable while preserving a reproducible, checksum-pinned download step.

To install the extension in Chrome:

1. Open `chrome://extensions`.
2. Enable Developer mode.
3. Select **Load unpacked**.
4. Choose the generated `dist/` directory.
5. Open the Source Sight toolbar menu and prepare the local model.

## Development and verification

```sh
npm run check       # TypeScript validation
npm run verify:model
npm run build
npm run test:smoke  # temporary Chrome profile and CDP smoke test
```

The smoke test loads `tests/smoke-page.html`, installs the built extension through Chrome DevTools Protocol, and waits for two completed image badges: an AI-generated fixture and a real photograph. It leaves Chrome open for 30 seconds after the results are printed; set `SOURCESIGHT_KEEP_OPEN_MS=60000` for one minute or `SOURCESIGHT_KEEP_OPEN_MS=0` for a non-interactive run. Chrome 137 and later require this CDP loading path for branded Chrome; the old `--load-extension` launch flag is not used.

For a clean rebuild, run `npm run clean` before `npm run build`.

For a larger accuracy check, put labeled images under `real/` and `ai/` in a local dataset directory and run `SOURCESIGHT_BENCHMARK_DIR=/path/to/dataset npm run benchmark`. See [BENCHMARK.md](BENCHMARK.md) for the dataset contract and scoring details. The dataset stays outside the repository.

To create a reviewer-ready submission archive, first download and verify the model, then run `npm run package:release`. The generated `source-sight-v*.zip` contains the MV3 extension, the verified ONNX model, and bundled ONNX Runtime assets with `manifest.json` at the archive root. Keep the ZIP out of Git and keep any signing key private.

## Repository layout

```text
public/       Chrome manifest, model manifest, and optional packaged weights
src/          Extension runtime, inference worker, preprocessing, and UI
scripts/      Build, model, and smoke-test utilities
tests/        Deterministic browser smoke page
```

The generated `dist/` directory, model weights, CRX package, and signing key are ignored and must not be committed.

## Privacy and licensing

Source Sight does not upload image bytes, page contents, browsing data, or inference results. The only intended network request is the one-time download of the pinned public model.
